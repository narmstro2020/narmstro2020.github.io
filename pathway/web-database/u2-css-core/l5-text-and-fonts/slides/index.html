Two fonts.
Not six.

One for reading, one for headings. Sizes that scale. Nothing centred that should not be.

A font stack is a list of fallbacks
body {
  font-family: "Lora", Georgia, "Times New Roman", serif;
}

Best first. If the browser does not have it, the next. The last word is a generic family — serif, sans-serif, monospace — and it always works.

Names with spaces go in quotes.

Google Fonts — one link per page
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Lora:ital,wght@0,400;0,700;1,400&amp;family=Source+Sans+3:wght@400;600;700&amp;display=swap" rel="stylesheet">
<link rel="stylesheet" href="style.css">

In the <head> of every page, above style.css. Pick your two weights and no more: every weight is a download.

rem, not px
UnitMeansWhen the user picks Large text
16pxsixteen pixels, alwaysnothing changes
1remthe user's text size — 16px by defaultit grows with it
1.5em1.5 × the parent's sizegrows, but compounds when nested

Headings in rem, and the ratio between them is the design: 2.4 to 1.4 to 1.05.

The type system
h1, h2 { font-family: "Source Sans 3", "Segoe UI", Arial, sans-serif; }
h1 { font-size: 2.4rem; line-height: 1.15; letter-spacing: -.01em; }
h2 { font-size: 1.4rem; }
nav a {
  text-transform: uppercase; letter-spacing: .06em;
  font-weight: 600; text-decoration: none;
}
blockquote { font-style: italic; }
cite       { font-style: normal; }   /* browsers italicise cite on their own */

Big text tightens, small caps loosen. text-transform changes the look without changing the HTML. font-style is italic or normal, and nothing else.

Alignment

Paragraphs are left-aligned. Always.

text-align: justify looks like a book and reads like a ransom note — the browser cannot hyphenate, so it stretches the spaces. center is for a footer line or a heading, never for a paragraph.

Prove it

Set your browser's text size to Large.

Reload. Everything on your site grows together.

That is what rem bought you. A site sized in px would not move.

Before you leave

  • Two fonts linked on all four pages, above style.css
  • Reading font on the body, heading font on headings and nav
  • Every font-size in rem
  • Still zero validator errors

Exit ticket: body at 1rem, h1 at 2.4rem, the visitor picks Large text. What happens, and why would 16px and 38px behave differently?
