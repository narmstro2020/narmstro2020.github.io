Higher column wins. Tie: the later rule wins. A nested rule counts every selector it sits inside.

DevTools, Styles panel: the losing rule is struck through. That is the count, drawn for you.

Inheritance

Passes down: color, font, line-height, text-align. Does not: border, padding, margin, background.

footer {
  a { color: inherit; }               /* does NOTHING: 0,0,0,2 loses to a:link 0,0,1,1 */
}

footer {
  a:link,
  a:visited {                         /* 0,0,1,2: wins the class column */
    color: inherit;
    text-decoration: underline;
  }
}

The footer link should be the footer's grey, not the site's green. The first rule is the one everyone writes. Count why it fails.

!important
p { color: red !important; }

Beats everything.
Delete it.

Project 2 scores zero on criterion 7 for a stylesheet that contains it.

Math functions
calc(1rem + 2vw)mix units: a rem plus a slice of the window. Spaces around + and − are required
min(50%, 22rem)whichever is smaller: a ceiling
max(2.75rem, 1em)whichever is larger: a floor
clamp(1.8rem, 1rem + 3vw, 2.6rem)the middle one, never under the first or over the last
Each one, once, on your site
h1 { font-size: clamp(1.8rem, 1rem + 3vw, 2.6rem); }   /* fluid type: drag the window */

.intro {
  .hero { width: min(50%, 22rem); }                    /* half the box, never over 22rem */
}

.detail {
  .crop { height: clamp(8rem, 30vh, 14rem); }          /* L13's vh, with a floor and a ceiling */
}

main {
  padding-left:  calc(1rem + 2vw);                      /* a rem plus a slice of the window */
  padding-right: calc(1rem + 2vw);
}
