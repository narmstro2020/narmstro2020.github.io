One box cannot be both
The same two lines, four times
body { max-width: none; padding: 0; }        /* later than L4's: the body is a band now */

header { padding: 2rem 1.5rem;
  h1 { max-width: 48rem; margin: 0 auto; } }
nav {
  ul { max-width: 48rem; margin: 0 auto; } }  /* on the ul: the bar itself stays full width */
main  { max-width: 48rem; margin: 1.5rem auto; }
footer { margin-top: 0; padding: 1.5rem;
  p  { max-width: 48rem; margin: 0 auto; } }

Reload after the first line and look at the mess. Then add the other four and watch the words go home.

A row of two columns
<div class="row">
  <section class="col"> ... </section>
  <section class="col"> ... </section>
</div>

.row {
  display: flow-root;                   /* contain the floats: L9 */
  margin: 0 -1rem;
  .col {
    float: left;
    width: 50%;
    padding: 0 1rem;
    h2 { clear: none; }                 /* L9's clear: both, switched off here only: L14 */
  }
}

The last float you will write. W3Schools lays its page out this way too; Flexbox (U3 L7) and Grid (U3 L8) are what replaced it.

Focus, only when it is the keyboard
a:focus, button:focus, input:focus, select:focus, textarea:focus {
  outline: none;                        /* never on its own */
}

a:focus-visible, button:focus-visible, input:focus-visible,
select:focus-visible, textarea:focus-visible {
  outline: 3px solid var(--accent);     /* L4's ring, back, for Tab only */
  outline-offset: 2px;
}

Click the form button: no ring. Press Tab until you reach it: ring. Both, or neither.

Heard, not seen
.visually-hidden {
  position: absolute; width: 1px; height: 1px;
  padding: 0; margin: -1px; overflow: hidden;
  clip-path: inset(50%); white-space: nowrap;
}

<a href="https://www.in.gov/dnr/state-parks/" target="_blank">the official park
  listing<span class="visually-hidden"> (opens in a new tab)</span></a>

@media (prefers-reduced-motion: reduce) {
  * { transition: none; animation: none; scroll-behavior: auto; }
}

Not display: none — that hides it from the screen reader too. Check your accent on white at WebAIM: it must pass.
