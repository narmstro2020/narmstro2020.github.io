Who is writing this

I am a sophomore at Warren Central and I have been to exactly three of Indiana's twenty-four state parks. That is the whole reason this site exists — I want a record of the rest.

Why this topic

Most park websites tell you the hours and the entrance fee. None of them tell you whether the trail is worth it. That is the part I am trying to write down while I still remember it.

Rugged trails, deep sandstone ravines, and hemlock groves make Turkey Run one of Indiana's most scenic state parks.

One thing that caught me out

I wanted to write about the <table> tag on this page and the table just disappeared. The browser was reading my example as a real tag instead of as text.

The fix is an entity — a code that stands in for a character the browser would otherwise treat as HTML:

The entities I actually needed
I typeThe page showsWhy I need it
&lt;<otherwise it starts a tag
&gt;>otherwise it ends one
&amp;&otherwise it starts an entity
&copy;©not on the keyboard
&nbsp;a space that never breakskeeps “7 am” on one line

The one that surprised me is &amp;. To write the ampersand code itself I have to escape the ampersand, which felt like a trick question until I thought about it.
