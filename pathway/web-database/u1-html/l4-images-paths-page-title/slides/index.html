One tag. Two attributes.
Both required.

src is a path — the same relative addressing you used for links last class. alt is writing, and it is not optional.

The first one of these you'll meet

There is no </img>.

An <img> has no content between tags — the content is the file.

Tags like this are called void elements. You'll meet <br>, <hr>, and <input> later. It's a category, not an exception.

Yesterday's idea, one step further. src="images/park.jpg" is a relative path — same as href="about.html", except now it points into a folder.

A path is directions
from where you're standing.

The / means "go inside." Everything is measured from the page that's asking.

Why alt is mandatory
read aloud
A screen reader says it out loud. Without it, a blind visitor gets "image" — or the filename.
fallback
If the image fails to load, the alt text shows instead. This will happen to you today.
bonus
It's the only part of an image a search engine can read.

alt="" is not the same as leaving it out — that means "this image is decoration, skip it."

Describe what it shows.

alt="image"Says nothing. The screen reader already said "image"
alt="park.jpg"The filename read aloud. Worse than nothing
alt="photo of a trail"Closer — but "photo of" is wasted words
alt="A narrow canyon trail with ladders bolted into the rock"That's the one. Someone who can't see it now knows what's there
