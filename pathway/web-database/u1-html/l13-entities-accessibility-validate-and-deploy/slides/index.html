The problem entities solve

You cannot type a < and mean it

<p>Use the <table> tag</p>

The browser reads that as a real table tag. Your sentence loses a word and gains an empty table.

Accessibility is not a feature
you add at the end

It is six things you have already been doing, checked.

  • One <h1> per page, headings in order
  • alt on every image
  • A <label> on every input
  • lang set on <html>
  • Semantic elements, not <div> soup
  • A skip link, so a keyboard user can jump the nav
The one new thing

The skip link

<body>
  <a class="skip-link" href="#main">Skip to main content</a>

Press Tab once on any site you like. Most good ones have this, and you have never seen it, because it only appears when somebody needs it.

The validator does not care
how hard you worked

validator.w3.org

Every page. Every error. Zero is the target, and it is a graded expectation on Project 1.

This is what “built to standards” means. Not an opinion, not a style preference — a machine either accepts it or it does not.
