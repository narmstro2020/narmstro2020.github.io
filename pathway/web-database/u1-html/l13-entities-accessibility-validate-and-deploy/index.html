  <h2>One thing that caught me out</h2>
  <p>I wanted to write about the <code>&lt;table&gt;</code> tag on this page and the
  table just disappeared. The browser was reading my example as a real tag instead of
  as text.</p>
  <p>The fix is an <strong>entity</strong> &mdash; a code that stands in for a character
  the browser would otherwise treat as HTML:</p>
  <table>
    <caption>The entities I actually needed</caption>
    <thead>
      <tr><th>I type</th><th>The page shows</th><th>Why I need it</th></tr>
    </thead>
    <tbody>
      <tr><td><code>&amp;lt;</code></td><td>&lt;</td><td>otherwise it starts a tag</td></tr>
      <tr><td><code>&amp;gt;</code></td><td>&gt;</td><td>otherwise it ends one</td></tr>
      <tr><td><code>&amp;amp;</code></td><td>&amp;</td><td>otherwise it starts an entity</td></tr>
      <tr><td><code>&amp;copy;</code></td><td>&copy;</td><td>not on the keyboard</td></tr>
      <tr><td><code>&amp;nbsp;</code></td><td>a space that never breaks</td><td>keeps
        &ldquo;7&nbsp;am&rdquo; on one line</td></tr>
    </tbody>
  </table>
  <p>The one that surprised me is <code>&amp;amp;</code>. To write the ampersand code
  itself I have to escape the ampersand, which felt like a trick question until I
  thought about it.</p>

  <h2>Rocky Hollow, in order</h2>
  <p>Shuffle these and you would be walking the ladders downhill in the dark, so this
  one is ordered.</p>
  <ol>
    <li>Park at the Nature Center lot, not the inn</li>
    <li>Cross the suspension bridge over Sugar Creek</li>
    <li>Turn right into the gorge at the Trail 3 marker</li>
    <li>Climb the ladder section &mdash; both hands, no phone</li>
    <li>Follow the creek bed until it opens out at Wedge Rock</li>
    <li>Come back on Trail 5 rather than the way you came</li>
  </ol>

  </section>

  <section id="trails">
  <h2>Trails, grouped by how hard they are</h2>
  <ul>
    <li>Easy
      <ul>
        <li>Trail 1 &mdash; paved, and the only one a stroller survives</li>
        <li>Trail 7 &mdash; flat, wooded, quiet on a weekday</li>
      </ul>
    </li>
    <li>Moderate
      <ul>
        <li>Trail 5 &mdash; the sensible way back out of the gorge</li>

      <ul>

    </li>

  <section id="glossary">
  <h2>Words the signs use without explaining</h2>
  <dl>
    <dt>Gorge</dt>
    <dd>A narrow canyon cut down through sandstone by the creek. Cold, and it stays
    wet days after the rain stops.</dd>

    <dt>Hemlock</dt>
    <dd>The dark evergreen growing out of the ravine walls. Left over from the last
    ice age, which is the single best fact about this park.</dd>

    <dt>Ladder section</dt>
    <dd>Steel rungs bolted straight into the rock face on Trail 3. Not optional &mdash;
    there is no way around it.</dd>
