My Site About Indiana State Parks

Welcome. This site is about the state parks in Indiana, which ones are worth the drive, and what you can actually do at each one.

Why I picked this

My family has been going to Turkey Run since I was small, and I found out there are twenty-three more state parks I had never heard of. I want to make a page for each one I visit this year.

The ones closest to Indianapolis are Fort Harrison and Shades. Both are under an hour, which matters when you are relying on someone else to drive you.

What I already know

Turkey Run has ladders bolted into the rock in some of the canyon trails. Trail 3 is the one everybody talks about and it is genuinely hard in wet weather.
