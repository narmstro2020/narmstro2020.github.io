The whole tag

href is an attribute — same idea as lang on your <html> tag.

Two kinds of address.

Relative
<a href="about.html">

A file sitting next to this one, in the same folder. Short, because it doesn't need to say where it starts from.

Like saying "the room next door." Only means anything if you already know where you're standing.
Absolute
<a href="https://www.nps.gov">

The entire address, from the protocol onward. Works from anywhere, on any site, forever.

Like a full street address. Longer, and it works from anywhere on earth.
Your own pages → relative. Somebody else's → absolute.

That's the rule. There is no third case today.

One more attribute.

<a href="https://www.nps.gov"
   target="_blank">the park service</a>

target="_blank" opens the link in a new tab, so your visitor still has your site open behind it.

External links: yes. You don't want to throw someone off your own site.
Your own pages: no. A new tab every time someone clicks "Home" is genuinely irritating.

  1. A second page — about.html, with its own full skeleton

  3. One external link to a real source about your topic, with target="_blank"
  4. Every link clicked and confirmed working by you

Nobody starts over. about.html is a new file in the same folder as the page you already have.
Build · Step 1

The second page.

<!DOCTYPE html>
<html lang="en">
<head>
  <title>About me</title>
</head>
<body>

  <h1>About me</h1>
  <p>Who I am and why I made this site.</p>

</body>
</html>
A page is not just content. Every new file gets the whole skeleton — doctype, html, head, title, body. A page missing it renders, and then behaves strangely in ways you can't see yet.
The error worth causing

Type About.html with a capital A.
Click it.

It works. On this computer.

Windows doesn't care about capitals. Web servers do. About.html and about.html are two different files to every server on the internet — so this link breaks the moment your site is real.
Filenames: all lowercase, no spaces, forever.
about.htmlRight
About.htmlWorks here, 404s on a real server
about me.htmlBecomes about%20me.html in the URL
Build · Step 3 — test it

A link you haven't clicked
is a link you don't know about.

  1. From index.html, click through to about.html
  2. From about.html, click back to index.html
  3. Click your external link — does it open in a new tab?
  4. Now check the tab you came from is still there
Broken links are the most common bug on the real web, and the only fix is the one you're doing right now: clicking them.
