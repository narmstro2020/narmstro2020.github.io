Build · Step 1 — 15 minutes

Upgrade what you already built

<input type="email"  id="email" name="email" placeholder="you@example.com" required>
<input type="number" id="visits" name="visits" min="0" max="24" value="0">
<input type="date"   id="when" name="when">

Same form as yesterday. Better types.

Build · Step 2

required

<input type="email" id="email" name="email" required>
One word, and the browser refuses to submit without it — and writes the error message itself.

Put it on the fields you genuinely need. Not all of them.

The classic bug

Radio buttons that all stay on

<input type="radio" id="near" name="distance" value="near">
<input type="radio" id="mid"  name="distance" value="mid">
<input type="radio" id="far"  name="distance" value="far">
Same name = one group. Different names and every button is its own group — so they all stay selectable at once.

Different ids, though — the labels need them.

Build · Step 4 — the good bit

Try to break your own form

  1. Submit it completely empty
  2. Put banana in the email field and submit
  3. Put 99 in a field with max="24"
  4. Now count how many lines of validation code you wrote
Zero. The browser did all of it.

One warning about free validation.

It runs in the browser, and the browser belongs to the user.
Anyone can turn it off.

It is there to help honest people fill the form in correctly. It is not security. Real checking happens on the server — Unit 6.
