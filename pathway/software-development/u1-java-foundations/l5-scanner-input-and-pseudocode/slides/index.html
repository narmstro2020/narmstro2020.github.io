The trap every Java programmer
meets exactly once.

int diff = in.nextInt();       // reads 2, LEAVES the Enter key behind
String name = in.nextLine();   // instantly returns "" — it ate the leftover
The fix: a bare in.nextLine(); after any nextInt(). Today is your once.

String playerName = in.nextLine().trim();
if (playerName.isEmpty()) {
    playerName = "Challenger";
