Anatomy

Every method, same four parts

static int calculateDamage(int power, boolean isCritical) {
//     |        |            +-- parameters (the inputs)
//     |        +-- name: a verb phrase
//     +-- return type: what comes back (void = nothing)
    return isCritical ? power * 2 : power;
}

Name it after what it gives you, not how it works.

The question everyone asks

Why static?

main is static, and a static method can only call other static methods directly.

static means it belongs to the class, not to an object. We do not have objects yet.
In two weeks we will — and most of these lose static.

This one surprises everyone

Java copies the argument

static void tryToHeal(int hp) {
    hp += 50;          // changes the COPY
}

int health = 40;
tryToHeal(health);
System.out.println(health);   // still 40
The method did nothing. The fix is return.
health = heal(health, 50);

Start with the easy ones

Methods that only print. No return value, nothing to get wrong.

static void printBanner(String text) {
    System.out.println("=".repeat(40));
    System.out.printf("  %s%n", text);
    System.out.println("=".repeat(40));
}
Build · Step 2 — 18 minutes

Now the ones that give something back

static boolean isAlive(int hp) {
    return hp > 0;
}

static int calculateDamage(int power, int roll) {
    if (roll >= 9) return power * 2;
    if (roll >= 3) return power;
    return 0;
}

Three returns in one method is fine. The first one that runs, wins.

Build · Step 3 — the big win

Extract the input validation

static int readChoice(Scanner in, int min, int max) {
    int choice;
    do {
        System.out.printf("Choose %d-%d: ", min, max);
        while (!in.hasNextInt()) {
            in.next();
            System.out.printf("Numbers only. Choose %d-%d: ", min, max);
        }
        choice = in.nextInt();
        in.nextLine();
    } while (choice < min || choice > max);
    return choice;
}
Twelve ugly lines you wrote in Lesson 8, now one line, every time you need it.
Build · Step 4

Overloading

static int calculateDamage(int power, int roll) { ... }
static int calculateDamage(int power, int roll, double critMultiplier) { ... }

Same name. Different parameter list. Java picks the right one by what you pass.

The parameters must differ — not just the return type. Two methods differing only in return type will not compile.
