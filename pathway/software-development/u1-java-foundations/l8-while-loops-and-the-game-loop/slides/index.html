The game loop

Every game ever made
is this shape.

int turnNumber = 1;
boolean playing = true;

while (playing) {
    // show the status
    // ask for an action
    // resolve it
    // let the enemy answer
    // check whether the fight is over
    turnNumber++;
}
The hard part

What goes inside?

ONCE — outsideEVERY TURN — inside

Asking your nameThe menu and the switch

Without this you cannot lose. Defend forever and nothing happens. The counterattack is what makes an ending real.

Build · three ways to end
if (!alive) {                     // fled
    playing = false;
} else if (enemyHealth <= 0) {    // won
    playing = false;
} else if (health <= 0) {         // lost
    playing = false;
}
alive is a sentinel — one value that means "stop." Your [F]lee case sets it.
Move !alive to last and then flee on low health. It'll tell you that you died. Order matters.
