If it's not working

incompatible types: String cannot be converted to int You put text in a number. Today's lesson — celebrate it
cannot assign a value to final variable XYou tried to change a constant
variable X might not have been initializedDeclared, but never given a value
cannot find symbolTypo, wrong case, or declared inside main and used outside
non-static variable X cannot be referenced from a static context Your constant is missing the word static
Why static? Because main is static, and a static thing can only reach other static things. We'll explain that properly in Unit 2.
