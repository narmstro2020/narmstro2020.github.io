Packaging

A JAR is a zip with a name badge

One file: every compiled class, plus a manifest that says start here.

javac -d out src/Main.java
jar --create --file ArenaGame.jar --main-class Main -C out .
java -jar ArenaGame.jar
Three flags
PieceMeans
-d outcompiled classes go in out, not next to the source
--main-class Mainthe manifest: “when run, start here”
-C out .go into out and take everything
java -jarno src, no javac, no folder to be in

no main manifest attribute means --main-class was left off.

The test that counts

Copy it to your Desktop.
Run it from there.

If it only works inside the project folder, it is not packaged.
