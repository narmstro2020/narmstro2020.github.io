Step 2a · where every number lives

The Inspector

Click a node in the Scene dock and the Inspector on the right fills with that node's properties. Different node, different list.

  1. Select the node first.
    Empty Inspector = nothing is selected
  2. Type in the filter box at the top — size, position, color
  3. Click the box, type the number, press Enter
    X and Y are two separate boxes
Can't find a property? Filter for it. That's the whole trick.
Step 2b · the part that draws

Set up the ColorRect

  1. Select ColorRect in the Scene dock
  2. Filter size → Layout → Transform → Size
    64 × 64
  3. Filter position → Position
    −32 , −32
  4. Filter color → click the swatch → any colour you like
A ColorRect keeps its numbers under Layout. Most other nodes don't. Filter — don't hunt.
Step 2c · the part that detects

Set up the CollisionShape2D

  1. Select CollisionShape2D
  2. Shape → click <empty> → New RectangleShape2D
  3. Click the shape that appears to open it → Size
    64 × 64 — it starts at 20 × 20
  4. Leave its Position at 0, 0
Type the size. Don't drag the orange dots. Dragging gets you 63.4 × 61.8 and you won't find out until Lesson 6.
Why Position −32, −32?

It slides the box back by half its width and half its height. Skip it and every collision feels wrong three lessons from now.

Step 5 · 14 minutes

Now we type it.
Together.

Six lines. I say every symbol out loud, you type it with me.

I will make mistakes on purpose and by accident. Both are the lesson. Watching an error appear and get fixed is how you learn to fix your own.

Four things, while we type

  • Indentation is not decoration. An indented line is inside the line above it. A wrong indent is a real error, not a style opinion.
  • ui_right and ui_left are names Godot already has, already wired to the arrow keys. We'll make our own in Project 2.
  • The underscore in _delta means "this exists, I'm not using it yet." Godot hands it to us every single frame. Next class we find out what it's for.
  • += means "add to what's already there." Every frame, five more pixels.

Run it. The square moves.

Step 6 · 8 minutes

Experiment

  • Change the 5 to 20. Too fast?
  • Change it to 1. Too slow?
  • Add up and down — ui_up, ui_down, and position.y
  • Swap a += for a -= and watch the controls invert
One change. Then play it. Then the next one.

Change three things at once and you won't know which one did it. This rule runs all year.
