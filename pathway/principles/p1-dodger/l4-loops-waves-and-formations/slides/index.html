Two kinds.

forYou know how many times — "spawn 3 hazards"
whileYou repeat until something changes — "keep re-rolling until the spot is clear"

Build · Step 1 — waves
var wave_size := 1

func _on_spawn_timer_timeout() -> void:
	var screen_size := get_viewport_rect().size

	for i in wave_size:
		var x := randf_range(32, screen_size.x - 32)
		spawn_hazard(Vector2(x, -50 - i * 90))
i is doing real work in -50 - i * 90. It staggers them vertically so they arrive in sequence, not as one solid wall.

Build · Step 2 — three loops
func _on_spawn_timer_timeout() -> void:
	var screen_size := get_viewport_rect().size
	var used_columns: Array[float] = []

	for i in wave_size:
		var x := 0.0
		var attempts := 0
		var too_close := true

		while too_close and attempts < 20:
			x = randf_range(32, screen_size.x - 32)
			too_close = false
			for taken in used_columns:
				if abs(x - taken) < 100.0:
					too_close = true
			attempts += 1

		used_columns.append(x)
		spawn_hazard(Vector2(x, -50 - i * 90))
The four characters that matter most

attempts < 20

Without it, if there's no clear spot left, that while loop never ends.

The game doesn't crash. It freezes. No error, no message — you have to kill it from Task Manager. Do not leave this line out.

I'll show you it happening on purpose in Lesson 6.

Build · Step 3 — difficulty

Add a second Timer to Main named DifficultyTimer — Wait Time 5.0, Autostart ✅

func _on_difficulty_timer_timeout() -> void:
	if $SpawnTimer.wait_time > 0.4:
		$SpawnTimer.wait_time -= 0.1
	if wave_size < 4:
		wave_size += 1

	for hazard in get_tree().get_nodes_in_group("hazards"):
		hazard.fall_speed += 25
That last loop is the whole point of the opener. It reaches every hazard alive right now — including ones spawned four seconds ago.
