Build · Process Mode

Three settings. Inspector, not code.

MainAlwaysmust still hear Enter while paused
PlayerPausableso you stop where you died
HazardPausableso hazards don't fall through GAME OVER
Player and Hazard have to be set on purpose. They're inside Main, and Inherit copies the parent — which is now Always. Leave them alone and they keep moving.
Build · restart
func _process(delta: float) -> void:
	if game_over:
		if Input.is_action_just_pressed("ui_accept"):
			get_tree().paused = false
			get_tree().reload_current_scene()
		return

	score += 100.0 * delta
	$ScoreLabel.text = "SCORE %d" % score
paused = false comes before the reload. Pause belongs to the game, not the scene — reload without clearing it and your brand-new game arrives already frozen.
